## How to Compile & Run Any Program

Using GCC:

```bash
# Compile (e.g., Program #1)
gcc "LEVEL 1 CODES/max_value_array_#1.c" -o max_value
./max_value

# On Windows:
gcc "LEVEL 1 CODES\max_value_array_#1.c" -o max_value.exe
.\max_value.exe
```
